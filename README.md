# TaskNotifier

Windowsでタスクを通知するアプリです。タスクを追加し、タイトルと通知タイミングを設定してください。通知が不要な作業は「TODO（通知なし）」で管理できます。

## 通知タイミング

- **1回だけ**：「通知時刻の決め方」で「1回だけ・日時指定」を選び、実行日と通知開始時刻を指定します。
- **指定回数だけ**：毎日の通知設定で「指定回数だけ通知する」をONにし、合計通知回数を入力します。通知間隔を設定すれば、同じ日に複数回通知できます。
- **無制限**：毎日の通知設定で「指定回数だけ通知する」をOFFにします。従来のタスクはこの動作です。

回数は日ごとにリセットせず、タスク全体で数えます。OS通知は送信成功時、独自ダイアログは「確認済み」または「実行して確認済み」で1回と数えます。スヌーズでは回数を消費しません。上限に達すると一覧で「完了」と表示され、以後は通知しません。

単発の指定日時にアプリが起動していなかった場合は、次回起動時に通知します。回数指定の定期通知は従来と同じく、通知候補をまとめて最新の1件だけ通知します。飛ばした候補は回数に含めません。

実行済み回数は再起動後も保持されます。タイトルだけの編集では回数を維持します。通知スケジュール・回数上限・条件を変更すると、実行状態をリセットして新しい設定で開始します。設定の複製・インポートも新しい実行状態で開始します。

PWA版も単発・回数指定に対応しますが、通知にはPWAを開いておく必要があります。ブラウザを閉じた状態での指定時刻通知は行いません。

## Web UIの更新

既存のビルドは `ci-generated/webview.part*` を復元して使用します。回数制限のUIとPWA処理は `web/limited-tasks.js` にあり、変更後は `python scripts/update-limited-webui.py` で圧縮データと検証ハッシュを更新します。`node web/limited-tasks.test.cjs` で生成物との一致と通知処理を確認できます。
